Проект Vacancies_hh 
Описание
Vacancies_hh — это инструмент для сбора, анализа и управления данными о вакансиях с платформы HeadHunter. Проект предоставляет удобный интерфейс для загрузки информации о компаниях и их вакансиях, а также выполнения аналитических запросов к собранным данным.

Основные возможности:
Сбор данных через API HeadHunter для заданного списка компаний

Хранение данных в PostgreSQL базе данных

Анализ вакансий с помощью встроенных запросов:

Список компаний с количеством вакансий

Все вакансии с детальной информацией

Средняя зарплата по всем вакансиям

Вакансии с зарплатой выше средней

Поиск вакансий по ключевому слову

Тестовый режим с mock-данными (без реального подключения к БД и API)

Установка и запуск
Требования
Python 3.13 или выше

PostgreSQL (для работы с реальной БД)

Poetry (для управления зависимостями)

Установка
Клонируйте репозиторий:

bash
git clone <url-репозитория>
cd vacancies-hh
Установите зависимости через Poetry:

bash
poetry install
Создайте файл .env в корне проекта и настройте подключение к БД:

env
DB_NAME=hh_vacancies
DB_USER=postgres
DB_PASSWORD=your_password
DB_HOST=localhost
DB_PORT=5432
Использование
Реальный режим (с PostgreSQL и API hh.ru)
bash
poetry run python main.py
Программа выполнит:

Создание базы данных и таблиц

Загрузку данных о 10 компаниях и их вакансиях через API hh.ru

Запуск интерактивного режима для анализа данных

Тестовый режим (с mock-данными)
bash
poetry run python test_main.py
В этом режиме:

Не требуется подключение к PostgreSQL

Данные генерируются автоматически

Можно тестировать функциональность без реальных запросов к API

Интерактивный режим
После загрузки данных программа предлагает меню для анализа:

text
СИСТЕМА АНАЛИЗА ВАКАНСИЙ
============================================================

Выберите действие:
1. Список компаний и количество их вакансий
2. Список всех вакансий
3. Средняя зарплата по всем вакансиям
4. Вакансии с зарплатой выше средней
5. Поиск вакансий по ключевому слову
0. Выход
Структура проекта
text
vacancies-hh/

├── db_manager.py          # Модуль управления PostgreSQL

├── pyproject.toml         # Конфигурация Poetry
└── .env                   # Переменные окружения
